# Security

Do not post WalletConnect pairing URIs, session keys, signatures, wallet credentials or private keys in issues. Discard an exposed pairing session.

Report vulnerabilities through this repository's private GitHub vulnerability reporting feature. Do not include live secrets or user records. Public issues are for non-sensitive reproducible defects only.

The signer app is separate; Web-only tests do not establish Secure Enclave or physical-device security. No automatic transaction submission or signing is authorized by connecting or downloading a QR.
